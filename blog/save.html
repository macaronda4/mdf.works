セーブデータはどこにあるのか
クラウド同期が消したもの

同期があるから安心、と思っていると足をすくわれます。同期は「同じ状態に保つ」仕組みであって、「失わないようにする」仕組みではありません。古いほうで上書きされることも、両方が残らないこともあります。仕組みを知ったうえで、備えを1つ足す話です。

ゲーム 2026年10月14日 約7分で読めます

目次

    置き場所は3種類ある

    同じ「セーブ」でも、置かれている場所が違います。 どこにあるかで、失いかたも守りかたも変わります。

    置き場所性質失う原因
    端末の中そのゲーム専用のフォルダ故障、初期化、誤削除
    配信サービスのクラウド起動と終了のたびに同期競合による上書き
    ゲーム会社のサーバーアカウントに紐づくアカウントを失うこと

    多くのゲームは1つ目と2つ目の組み合わせです。 つまり手元にあるものを、起動と終了のときに送り合っている状態です。 常時つながっているわけではありません。ここが、あとで効いてきます。

    なぜ巻き戻るのか

    同期は、次のような流れで動きます。

    1. 起動時、クラウド側と手元を比べる 更新の時刻を見て、どちらが新しいかを判断します。
    2. 新しいほうを採用する 通常はこれで問題ありません。片方だけが進んでいる状態なら、正しく選ばれます。
    3. 終了時、手元の状態を送る 遊んだぶんがクラウドに反映されます。

    破綻するのは、3番目が実行されなかった場合です。

    • 通信が切れた状態で遊んで、そのまま終了した
    • ゲームが強制終了した
    • 同期が終わる前にパソコンを切った
    • そもそもオフラインのまま遊び続けた

    この状態で別の端末を起動すると、クラウドには古い状態が入っています。 そちらで遊んで終了すると、古い状態を土台にした続きが送られます。 結果として、遊んでいない側の進行が消えます。

    多くの配信サービスは、食い違いを検出するとどちらを使うか聞いてきます。 ここで慌てて選ぶと事故になります。 表示されている日時と、プレイ時間をよく見てください。 「クラウド側」「ローカル側」という表現だけでは、どちらが自分の進行か分かりません。

    いちばん多い失敗

    経験上、次の組み合わせが危ないです。

    • 携帯機とパソコンを行き来する — 移動中はオフラインになりがちで、送信が済まないまま次に進みます
    • スリープで放置している — 終了処理が走っていないので、同期も走りません
    • 同時に2台で起動する — 両方が別々に進み、あとから来たほうが上書きします
    • 返金や再インストールの直後 — 手元が空の状態で起動すると、空の状態が「新しい」と判断されることがあります

    手動で控えを取る

    同期に任せきりにしないのが、いちばん確実な備えです。 フォルダを1つコピーするだけで済みます。

    1. 保存場所を調べる ゲームごとに違います。配信サービスの管理画面から辿れる場合もありますし、利用者ごとの設定を置く場所にあることも多いです。まず場所を知るのが最初の一歩です。
    2. 区切りのいいところでコピーする 章を進めた、大きな選択をした、育成が一段落した。戻れなくなったら痛い場面の直後に取ります。
    3. 日付を付けて残す フォルダ名に日付を入れておきます。書き方はファイル名で困らないための決めごとのとおり、年から並べると順に並びます。
    4. 端末の外に置く 同じ端末に置いておくと、故障のときに一緒に失われます。クラウドか外付けに1つ出しておきます。
    取るのは数分に一度ではなく、節目だけで十分です。 完璧を目指すと続きません。 「あのときに戻れたら」と思う場面は限られているので、 そこだけ押さえておくほうが現実的です。

    巻き戻ってしまったら

    1. まず、そのゲームを起動しない 起動するたびに同期が走り、古い状態が確定していきます。手を止めるのが最初の対処です。
    2. 同期を切る 配信サービスの設定で、そのゲームだけ同期を無効にできることがあります。これ以上の上書きを止めます。
    3. もう一方の端末を確認する まだ同期していない端末に、新しい状態が残っている可能性があります。その端末をネットにつなぐ前に、フォルダをコピーして退避します。
    4. サービス側に古い版が残っていないか調べる 過去の版を保持している仕組みがある場合があります。問い合わせ窓口が対応してくれることもあります。
    5. 戻せないなら、そこで区切る 残念ですが、対処のしようがない場合もあります。次からは節目で控えを取る、という結論に落ち着きます。

    同期を使わないという選択

    1台でしか遊ばないなら、同期を切ったほうが安全な場合があります。 上書きの事故が起きなくなるからです。

    ただしその場合、端末が壊れたら終わりになります。 同期を切るなら、手動の控えとセットにしてください。 どちらか一方だけという状態が、いちばん危ない構成です。

    この構図は、写真やファイルの話とまったく同じです。 同期は同じ状態に保つもの、バックアップは過去を残すもの。 詳しくはスマホのバックアップに入らないものにも書きました。

    引き継ぎの方法を先に確認しておく

    スマートフォンのゲームは、また別の仕組みです。 端末ではなく、アカウントに紐づいていることが多い。 ここで確認しておく点があります。

    1. 何に紐づいているかを知る サービスのアカウント、SNSの連携、あるいはその端末自体。最後のものがいちばん危なく、端末を失うと戻せません。
    2. 引き継ぎ用の情報を発行して控える 専用のコードを発行する形式があります。有効期限が設定されていることが多いので、発行しただけで安心せず、期限を確認します。
    3. 控えの置き場所を決める その端末のメモに書くと、端末を失ったときに一緒に消えます。パスワードの管理に使っている場所か、紙に書いて別の場所へ。
    4. 連携先のアカウントを守る SNS連携にしている場合、そのSNSを失うとゲームも失います。二段階認証はそちらにも必要です。
    機種変更の順番を間違えると戻せません。 古い端末を初期化する前に、引き継ぎの手続きを済ませてください。 この構図はスマホのバックアップに入らないものの 認証アプリとまったく同じで、先に消してしまうと打つ手が無くなる種類の失敗です。

    改造や外部の道具を使う場合

    追加要素を入れて遊ぶ場合、セーブの扱いが変わります。

    • 依存が生まれる — 追加要素を入れた状態で保存すると、外したときに読み込めなくなることがあります
    • 更新で壊れる — 本体が更新されると、追加要素が対応するまで遊べなくなります。更新前のセーブを残しておくと戻れます
    • クラウド同期と相性が悪い — 追加要素のデータが同期の対象外だと、別の端末では読めません

    対処はひとつで、入れる前のセーブを別に保存しておくことです。 フォルダをコピーするだけなので、数秒で終わります。 戻れる状態を作ってから試すのは、どんな実験でも同じ原則です。

    遊べなくなる別の理由

    セーブデータが無事でも、遊べなくなることがあります。 データの話とは別に、知っておくと備えができます。

    • 配信が終了する — 購入済みのものは遊べることが多いのですが、再ダウンロードができなくなる場合があります。手元に置いておくかどうかの判断材料になります
    • オンライン機能が終了する — 認証がサーバー側にある場合、単独では起動しなくなることがあります
    • 権利の移動で配信が止まる — 楽曲や映像の利用許諾が切れると、その部分だけ差し替えられたり、配信自体が止まったりします
    • 環境が対応しなくなる — OS が新しくなり、古い作品が動かなくなる

    長く遊びたい作品があるなら、手元に導入ファイルを保存しておく選択肢があります。 それが許されている配信形態かどうかは、購入時の条件によります。 セーブデータだけ守っても、本体が入手できなければ意味がないという点は、 意外と見落とされます。

    とはいえ、すべての作品にこれをやる必要はありません。 何十時間もかけたもの、もう一度は遊べないものだけで十分です。 自分にとってそれが何本あるかを考えると、たいてい片手で収まります。 その数本だけ、控えを取っておく。それが現実的な落としどころでした。

    同期は便利な仕組みで、切る必要はありません。 ただ「任せきりにしない」という一点だけ持っておくと、 最悪の事態が避けられます。 節目でフォルダを1つコピーする。それだけの手間で、数十時間が守れます。

    まとめ

    • 置き場所は端末・配信サービス・ゲーム会社の3種類
    • 同期は起動と終了のときに走る。常時ではない
    • 送信が済まないまま別の端末で遊ぶと、進行が消える
    • 食い違いの確認画面では、日時とプレイ時間を見る
    • 節目でフォルダをコピーして、端末の外に置く
    • 巻き戻ったら、まず起動しない。手を止めるのが最初の対処
