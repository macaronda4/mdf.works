144Hzで何が変わるのか
遅延はどこで積まれているか

60Hz から 144Hz にすると、確かに滑らかになります。ただし「滑らかさ」と「反応の速さ」は別の話です。前者は画面が書き換わる間隔、後者は操作が絵に出るまでの合計。さらに平均の枚数では見えない引っかかりもあります。3つを分けないと、お金をかける場所を間違えます。

ゲーム 2026年9月2日 約8分で読めます

目次

    まず3つの言葉を分ける

    混ざりやすいものを、先に切り離します。この3つはそれぞれ別の原因で悪くなり、別の対策で良くなります。

    呼びかた中身悪いとどう感じるか
    書き換えの間隔画面が1秒に何回描き直されるか動くものがカクカクして見える
    反応までの時間操作してから、結果が光になるまで照準が遅れてついてくる、ぬるい
    1枚あたりの揺れ絵と絵の間隔がどれだけ揃っているか平均は出ているのに時々つっかえる

    144Hz が直接改善するのは1番目です。約6.9ミリ秒ごとに絵が更新されます。60Hz なら約16.7ミリ秒。 動いているものの見やすさは、ここで決まります。 2番目はいくつもの段階の合計で、3番目は平均の数字にまったく現れません。順に見ていきます。

    反応までの時間を分解する

    マウスを動かしてから、その結果が目に届くまでに通る場所を並べます。 数値は一般的な目安で、環境によって変わります。

    1. マウスが動きを報告する 報告の間隔は設定で変わります。1000回/秒なら平均0.5ミリ秒ほど。ここは既に十分小さく、さらに上げても合計にはほとんど効きません。
    2. ゲームが操作を受け取り、次の絵を作る いちばん大きく、しかも自分で変えられます。毎秒60枚しか作れていなければ1枚あたり16.7ミリ秒、240枚なら4.2ミリ秒。モニタが144Hzでも、絵が60枚しか無ければ埋まりません。
    3. できた絵が順番待ちをする 作った絵をすぐ出さず、数枚ためてから出す仕組みがあります。枚数が揺れても表示が途切れない代わりに、ためた枚数ぶん遅れます。3枚ためていれば、それだけで数十ミリ秒になることがあります。
    4. ケーブルを通って届く 1ミリ秒に満たない程度。ここを気にする段階ではありません。
    5. モニタが受け取って処理する 製品差が大きい部分です。映像を加工する機能が有効だと、ここで数十ミリ秒増えることがあります。テレビをモニタ代わりにすると重くなりやすいのは、主にここです。
    6. 画素の色が実際に変わる 液晶が色を切り替える時間。速いパネルなら数ミリ秒、遅いと十数ミリ秒。ここが遅いと、動くものに尾を引きます。
    合計のうち、2 と 3 と 5 が大半です。 つまり「絵を何枚作れているか」「ためずに出しているか」「モニタが余計なことをしていないか」。 マウスやケーブルを替えても、この3つが直っていなければ体感は変わりません。 いちばん小さい項目から手を付けてしまうのが、よくある遠回りです。

    平均の枚数では見えないもの

    平均で毎秒120枚出ていても、快適とは限りません。 平均は1秒間の合計を割っただけなので、その中の分布を隠します。

    例えば、ほとんどの絵が8ミリ秒間隔で出ていて、1秒に数回だけ40ミリ秒空くとします。 平均は良い数字になりますが、体感としては数回つっかえた1秒です。 人間は平均ではなく、いちばん悪かった瞬間を覚えています。

    そこで見るのが、1枚あたりの間隔そのものです。 よく使われる指標に「下位1%」があり、 悪いほうから1%の絵がどれだけ待たされたかを表します。 平均が高いのに下位1%が低い構成は、数字ほど快適ではありません。

    測りかた： 多くの計測ソフトに、平均だけでなく間隔の推移をグラフで出す機能があります。 平らな線が続いていれば良く、棘のように跳ね上がる点があれば、そこが引っかかりです。 棘の原因は描画とは限らず、記憶装置の読み込み待ちや、 裏で動いている別の処理であることもよくあります。

    可変リフレッシュレートは何をしているのか

    絵の枚数は常に一定ではありません。一方、モニタの書き換えは決まった間隔で来ます。 この2つがずれると、1枚の絵の上下で別々の絵が表示される裂けが起きます。

    従来の対策は、モニタの書き換えに合わせて絵を待たせる方法でした。 裂けは消えますが、待つぶん遅くなります。しかも間に合わなかった場合、 次の機会まで丸ごと待つことになるので、枚数が大きく落ちます。

    可変リフレッシュレートは、逆にモニタ側が絵の到着に合わせて書き換える仕組みです。 裂けが出ず、待たせる時間も最小限になります。対応していれば、有効にしておく価値があります。

    やりかた裂け遅延枚数が落ちたとき
    何もしない出るいちばん小さいそのまま
    モニタに合わせて待たせる出ない大きい大きく落ち込む
    可変リフレッシュレート出ない小さいなめらかに追従する

    ひとつ注意があります。可変で追従できる範囲には下限と上限があり、 上限を超えるとただ待たされる状態に戻ります。 上限より少しだけ低いところに枚数の上限を設定しておくと、 常に可変の範囲に収まって安定します。

    パネルと、残像対策の副作用

    切り替えの速さはパネルの種類でおおよそ決まります。 そのうえで、多くのモニタには切り替えを速めるための補正が入っています。

    これは電圧を強めにかけて色の変化を急がせる仕組みで、 強くしすぎると目標を通り越して、逆向きの残像が出ます。 動く物体の後ろに明るい影がついてくる現象がこれです。 補正の強さは設定で段階的に選べることが多いので、 いちばん強い設定が最良とは限りません。中間で止めるのが無難です。

    もうひとつ、残像を減らすためにバックライトを短く点滅させる機能があります。 輪郭ははっきりしますが、画面が暗くなり、可変リフレッシュレートと同時に使えないことが多く、 ちらつきが苦手な人には向きません。効果と副作用の差が大きい機能です。

    効く順番

    1. 本当に144Hzで動いているか確認する OSの設定画面で、実際のリフレッシュレートを見ます。挿しただけでは60Hzのままのことがよくあります。ケーブルの規格が足りない場合も、上限が下がります。ここが最も多い取りこぼしです。
    2. モニタ側の映像加工を切る 補間・ノイズ低減・映画向けの映像モードは、そのぶん遅らせます。ゲーム向けの表示モードは、これらをまとめて止める設定であることが多いです。
    3. 可変リフレッシュレートを有効にする モニタ側とパソコン側の両方で有効にします。片方だけでは効きません。あわせて枚数の上限を、対応範囲の少し下に置きます。
    4. 絵の枚数を上げる 画質設定を下げるのがいちばん直接的です。特に影と反射の設定は、見た目の割に負荷が大きい部分です。
    5. ためる枚数を減らす ドライバやゲームの設定にあります。減らすと反応が早くなり、代わりに枚数が不安定なときに揺れやすくなります。
    6. 引っかかりの原因を別に探す 平均が足りているのにつっかえる場合、描画以外が原因です。記憶装置の速度、常駐しているソフト、録画や配信の処理などを疑います。

    240Hz まで行く意味はあるか

    間隔だけを見ると、60Hz から144Hz は約10ミリ秒の短縮、144Hz から240Hz は約2.7ミリ秒の短縮です。 効き目は等間隔ではなく、最初の一段がいちばん大きいということになります。

    そのうえで、240Hz を活かすには絵を毎秒240枚作り続ける必要があります。 先に「いま何枚出ているか」を測ってから決めるのが確実です。

    回線の速さは、ここには効きません。 対戦での「相手が先に撃っていた」は、手元の遅延と通信の遅延が混ざった結果です。 通信のほうは別の場所で積まれているので、 Ping はどこで生まれるのかのほうを見てください。 手元を詰めても、通信で100ミリ秒待っていれば、そちらが支配します。

    測ってから決める

    ここまでの話は、すべて自分の環境で測れば数字が出ます。 買い替えの前に30分かけるだけで、投資先がはっきりします。

    1. いま何枚出ているかを、遊びながら見る 常時表示できる計測ソフトを入れて、実際に遊ぶ場面で見ます。待機画面ではなく、いちばん混雑する場面の数字が重要です。人が多い、爆発が起きる、視界が開ける。そこが最低値になります。
    2. 平均ではなく、間隔の推移を見る グラフが平らなら良く、棘のように跳ねる点があれば引っかかりです。棘が出る場所を覚えておくと、原因の見当がつきます。特定の場所に入るときだけ跳ねるなら、読み込み待ちの可能性が高い。
    3. 設定を1つずつ変えて、同じ場面で比べる まとめて変えると、何が効いたか分かりません。影の品質、反射、描画距離あたりから1つずつ。見た目の変化に対して数字の変化が大きい設定が、下げる価値のある設定です。
    4. 反応の速さは、動画で確かめる 専用の測定器がなくても、高速で撮影できるカメラがあれば近いことができます。マウスを動かした瞬間と画面が動いた瞬間の差を、コマ数で数えます。設定変更の前後で比べれば、相対的な効果は分かります。
    数字を見ずに機材を替えると、効かない場所に払うことになりがちです。 平均が144枚に届いていないなら、モニタより先に描画側です。 平均は出ているのに棘が多いなら、記憶装置か常駐ソフトです。 反応が鈍く感じるのに数字は良いなら、モニタ側の処理を疑います。

    まとめ

    • Hz が決めるのは書き換えの間隔。反応の速さはいくつもの段階の合計
    • 合計の大半は絵を作る時間・ためる枚数・モニタ側の処理
    • 平均の枚数は分布を隠す。いちばん悪かった瞬間が体感を決める
    • 可変リフレッシュレートは裂けと遅延の両方に効く。上限の少し下に枚数を止める
    • 残像対策の補正は強すぎると逆向きの残像が出る。中間で止める
    • 効き目は等間隔ではない。60→144 が最も大きく、その先は伸びが小さい
