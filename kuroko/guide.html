Kuroko の使い方

読み込みから保存まで、実際の画面に沿って説明します。うまく検出されないときの調整方法も後半にまとめました。

最終更新：2026年8月13日

1. 画像を読み込む

読み込みかたは3通りあります。どれを使っても結果は同じです。

  • 貼り付け：スクリーンショットを撮った直後に Ctrl＋V（Mac は ⌘＋V）。クリップボードから直接取り込めるので、いちばん手数が少ない方法です。
  • ドラッグ＆ドロップ：画面上にファイルを放り込みます。複数ファイルをまとめて落とせます。
  • ファイルを選ぶ：右上の「画像を開く」ボタンから選択します。スマートフォンではカメラロールが開きます。

複数枚を読み込むと、画面下にサムネイルの一覧が並びます。クリックで切り替えられ、それぞれのマスクは別々に保持されます。

2. 自動検出を実行する

「自動検出」パネルの「この画像を自動検出」を押すと、アイコンと名前の行にマスクが並びます。 解析には画像の大きさに応じて数秒かかります。

アイコンと名前の処理を選ぶ

設定初期値説明
アイコンの処理モザイクぼかし・塗りつぶしにも変更できます。アイコンは絵柄なのでモザイクで十分なことが多いです。
名前・ID行の処理ダミー名に置き換え周囲の色で塗ったうえに User 01 と描き直します。誰の発言かの区別を残したいときに便利です。
名前が隣にないアイコンは無視するオン発言者のアイコンには必ず名前が並びます。オフにすると、サーバー一覧のアイコンやボタンなど丸いもの全てが対象になります。
既存のマスクを残すオンオフにすると、実行前に手動で作ったマスクも消えます。

「検出の積極性」の使い分け

5段階のスライダーです。標準（3）で足りないときだけ動かしてください。

  • 取りこぼすときは上げます。背景と同系色で輪郭が見えにくいアイコンや、装飾フレーム付きのアイコンは、4〜5でようやく拾えることがあります。
  • 関係ないものまで拾うときは下げます。絵文字やボタンが対象になってしまう場合に効きます。
コツ： まず標準で実行し、結果を見てから調整するのが確実です。「既存のマスクを残す」をオフにしてから再実行すると、前回の結果が消えて比較しやすくなります。

同じ人に同じ仮名が付く仕組み

検出したアイコンの色の並びを小さな指紋のような値に変換し、近いもの同士を同じ人物として束ねています。 そのため、同じ人が何度発言していても仮名は変わりません。返信プレビューに出てくる小さなアイコンも、 本人と同じ番号になります。

3. 手作業で直す

自動検出は下書きです。仕上げは手で調整します。

マスクを足す

左のツールからモザイク・ぼかし・塗りつぶし・ダミー名のいずれかを選び、画像の上をドラッグします。 離した時点でマスクが確定し、一覧に追加されます。

マスクを動かす・大きさを変える

選択ツール（キーボードの V）に切り替えると、マスクをドラッグで移動できます。 選択中のマスクには8つのハンドルが出るので、角や辺をつまんで大きさを変えられます。 ハンドルは選択ツール以外でも操作できます。

マスクを消す

マスク一覧の各行にある × を押すか、選択した状態で Delete キーを押します。 「すべて削除」で一括消去もできます。操作は Ctrl＋Z で戻せます。

数値で正確に合わせる

マスクを選ぶと X・Y・W・H の入力欄が出ます。1ピクセル単位で位置と大きさを指定できるので、 端がわずかに足りないときはここで詰めるのが早いです。ダミー名を選んだ場合は表示する文字も変更できます。

4. 書き出して保存する

「PNGで書き出す」を押すと、仕上がった画像が表示されます。保存の方法は環境によって使えるものが変わるため、 複数の手段を用意しています。

  • 画像を長押し（パソコンでは右クリック）→ 画像を保存。ブラウザ自身の機能なので、どんな環境でも使えます。確実なのはこれです。
  • 共有・写真に保存：スマートフォンで表示されます。OS の共有シートから写真アプリへ保存できます。
  • 名前を付けて保存：パソコンの Chrome / Edge で表示されます。通常の保存ダイアログが開きます。
  • ダウンロード / 新しいタブで開く / コピー：環境が許可していれば動作します。
ボタンを押しても何も起きないとき： ページが他のサイトに埋め込まれて表示されている場合、ブラウザ側の制限でダウンロードが禁止されていることがあります。 その場合は画像の長押し（右クリック）で保存してください。

書き出しは PNG への再エンコードです。元画像に含まれていた Exif（撮影日時・位置情報など）は結果には引き継がれません。

自動検出は何を見ているのか

仕組みを知っておくと、うまくいかないときの見当が付けやすくなります。Kuroko は次の順で判断しています。

  1. 輪郭の向きから円を探す。画像の明暗の変化（勾配）を求め、各点が「自分の正面方向にある中心」に投票します。票が集まった位置が円の中心の候補です。
  2. 候補を二つの尺度で検証する。円周のうちどれだけが実際の輪郭で覆われているか、そして「平らな面の上に置かれた円盤」に見えるかどうか。この二つを同時に満たすものだけを採用します。文字や四角形はここで落ちます。
  3. 同じ位置に並ぶアイコンを列とみなす。2つ以上が同じ横位置・同じ大きさで見つかれば、そこはアイコンの列です。列の残りは輪郭ではなく「そこに何かあるか」で判定するため、装飾フレームで輪郭が崩れたアイコンや、背景と同系色のアイコンも拾えます。
  4. 名前の行を切り出す。アイコンの右側の帯から、その場所の背景色を測り、文字のある行を抜き出します。本文との間の空白行で区切るので、メッセージ本文は覆いません。

つまり、円形でないアイコン（Slack や LINE の角丸四角など）は苦手です。 また、アイコンが1つしかない画像では「列」を作れないため、輪郭がはっきりしない場合は検出できません。 いずれの場合も手動ツールをお使いください。

うまくいかないときの対処

アイコンが1つも検出されない

「検出の積極性」を4〜5に上げてください。それでも駄目な場合は、「名前が隣にないアイコンは無視する」をオフにしてみてください。名前の行が読み取れないレイアウトだと、この条件で全て除外されることがあります。

関係ない場所にマスクが付く

積極性を下げるか、マスク一覧から不要な行を × で消してください。マスク一覧の行をクリックすると、その場所が画像上で強調されるので、どれが余分かを確認できます。

マスクがアイコンより小さくて端がはみ出す

そのマスクを選んで、ハンドルを引くか W・H の数値を大きくしてください。装飾付きアイコンでは実体の測定に失敗することがあります。

名前のマスクが本文まで覆ってしまう

マスクを選んで H を小さくしてください。行間が極端に詰まったスクリーンショットでは、名前の行と本文の行が分離できないことがあります。

ダミー名の文字が切れて表示される

枠が狭いと文字を縮めて収める仕様ですが、それでも読みにくい場合は W を広げるか、「置き換える文字列」を短くしてください。

解析が遅い、途中で固まる

解析対象は長辺1280ピクセルに縮小してから処理していますが、それでも古い端末では数秒かかります。極端に大きい画像（数千ピクセル四方）は、あらかじめ縮小してから読み込むと快適です。
